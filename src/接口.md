# 共用模块

## 1. 登录模块

### 接口信息
- 请求路径：`/api/user/login`
- 请求方式：POST

### 请求参数
| 字段名   | 类型   | 必填 | 说明   |
|----------|--------|------|--------|
| username | String | 是   | 用户名 |
| password | String | 是   | 登录密码 |

### 请求示例
```json
{
  "username": "2024001",
  "password": "123456"
}
```

### 返回参数
| 字段名 | 类型   | 必填 | 说明              |
|--------|--------|------|-------------------|
| code   | int    | 是   | 1=成功，0=失败    |
| mes    | String | 是   | 返回信息          |
| data   | Object | 否   | token 及用户信息 |

### 返回示例
```json
{
  "code": 1,
  "mes": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userId": "2024001",
    "username": "张三",
    "status": 1
  }
}
```

# 管理员模块

## 1. 教师管理

### 1.1 新增教师
- **请求路径**：`/admin/teacher/insert`
- **请求方式**：POST

| 字段名    | 类型   | 必填 | 说明     |
|-----------|--------|------|----------|
| teacherNo | String | 是   | 教师工号 |
| name      | String | 是   | 姓名     |
| gender    | int    | 否   | 0=女，1=男 |
| title     | String | 否   | 职称     |
| phone     | String | 否   | 电话     |
| email     | String | 否   | 邮箱     |

### 1.2 查询教师列表（分页）
- **请求路径**：`/admin/teacher/list`
- **请求方式**：POST

| 字段名    | 类型   | 必填 | 说明         |
|-----------|--------|------|--------------|
| teacherNo | String | 否   | 工号（模糊） |
| name      | String | 否   | 姓名（模糊） |
| pageNum   | int    | 否   | 页码，默认1  |
| pageSize  | int    | 否   | 每页条数，默认20 |

**返回 data 结构**：
```json
{
  "records": [...],
  "total": 100,
  "pages": 5
}
```

### 1.3 编辑教师
- **请求路径**：`/admin/teacher/update`
- **请求方式**：POST

| 字段名    | 类型   | 必填 | 说明     |
|-----------|--------|------|----------|
| id        | Long   | 是   | 主键ID   |
| name      | String | 是   | 姓名     |
| gender    | int    | 否   | 0=女，1=男 |
| title     | String | 否   | 职称     |
| phone     | String | 否   | 电话     |
| email     | String | 否   | 邮箱     |

> 工号 teacherNo 不允许修改

### 1.4 删除教师（逻辑删除）
- **请求路径**：`/admin/teacher/delete`
- **请求方式**：POST

| 字段名 | 类型   | 必填 | 说明     |
|--------|--------|------|----------|
| userId | String | 是   | 教师工号 |

### 1.5 重置密码
- **请求路径**：`/admin/teacher/resetPassword`
- **请求方式**：POST

| 字段名 | 类型   | 必填 | 说明     |

# 教师模块

## 1. 我的课程
- **请求路径**：`/teacher/course/list`
- **请求方式**：POST
- **说明**：查询当前教师所教授的课程列表

## 2. 课程学生列表
- **请求路径**：`/teacher/student/list`
- **请求方式**：POST
- **说明**：根据排课记录查询该课程下的学生列表

| 字段名 | 类型 | 必填 | 说明     |
|--------|------|------|----------|
| arrangementId | Long | 是 | 排课记录ID |

## 3. 录入/修改成绩
- **请求路径**：`/teacher/score/save`
- **请求方式**：POST

| 字段名      | 类型       | 必填 | 说明               |
|-------------|------------|------|--------------------|
| studentId   | Long       | 是   | 学生ID             |
| courseId    | Long       | 是   | 课程ID             |
| teacherId   | Long       | 是   | 教师ID             |
| classId     | Long       | 否   | 班级ID             |
| semester    | String     | 否   | 学期               |
| usualScore  | BigDecimal | 是   | 平时分（40%）      |
| finalScore  | BigDecimal | 是   | 期末考试分（60%）  |
| comment     | String     | 否   | 评语               |

> 总评成绩 score = usualScore * 0.4 + finalScore * 0.6

## 4. 发布成绩
- **请求路径**：`/teacher/score/publish`
- **请求方式**：POST

| 字段名 | 类型 | 必填 | 说明     |
|--------|------|------|----------|
| scoreId | Long | 是 | 成绩记录ID |

> 发布后设置 `is_viewable = 0`，学生需先完成评教才能查看

## 5. 查看评价统计
- **请求路径**：`/teacher/evaluation/stat`
- **请求方式**：POST
- **说明**：查看当前教师收到的评价统计（平均分、各维度分数）

# 学生模块

## 1. 待评价课程列表
- **请求路径**：`/student/course/list`
- **请求方式**：POST
- **说明**：查询当前学生需要评价的课程（已发布成绩且未评价）

## 2. 提交教师评价
- **请求路径**：`/student/evaluation/submit`
- **请求方式**：POST

| 字段名        | 类型       | 必填 | 说明                  |
|---------------|------------|------|-----------------------|
| teacherId     | Long       | 是   | 教师ID                |
| courseId      | Long       | 是   | 课程ID                |
| teachingScore | int        | 是   | 教学态度（1-25）      |
| contentScore  | int        | 是   | 教学内容（1-25）      |
| methodScore   | int        | 是   | 教学方法（1-25）      |
| effectScore   | int        | 是   | 教学效果（1-25）      |
| totalScore    | int        | 是   | 总评分（1-100）       |
| comment       | String     | 否   | 评价留言              |

> 提交后该课程成绩变为可查看（`is_viewable = 1`）

## 3. 查看成绩
- **请求路径**：`/student/score/list`
- **请求方式**：POST
- **说明**：查询当前学生已评价完成的成绩列表

**返回 data 结构**：
```json
[
  {
    "courseName": "Java程序设计",
    "teacherName": "张三",
    "semester": "2024-2025-1",
    "usualScore": 85.00,
    "finalScore": 90.00,
    "score": 88.00,
    "comment": "表现优秀"
  }
]
```
