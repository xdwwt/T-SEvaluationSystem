# 共用模块

## 1. 登录模块

### 接口信息

- 请求路径：`api/user/Login`
- 请求方式：POST

### 请求参数

| 字段名      | 类型     | 必填 | 说明   |
|----------|--------|----|------|
| username | String | 是  | 用户名  |
| password | String | 是  | 登录密码 |

### 请求示例（JSON）

```json
{
  "username": "Tom",
  "password": "123456"
}
```

### 返回参数

| 字段名  | 类型     | 必填 | 说明    |
|------|--------|----|-------|
| code | int    | 是  | 返回状态码 |
| mes  | String | 是  | 返回信息  |
| date | Object | 否  | 返回数据  |
